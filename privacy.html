Privacy Policy – SoukNova (Demo)

Last updated: 18 November 2026

SoukNova is a demonstration marketplace application. This policy describes how the demo handles information.

Information we process

  • Account data created via Supabase Auth (anonymous session or email if enabled).
  • Cart and order data stored in the connected Supabase project.
  • Device information necessary for the app to function (standard Expo / React Native).

How we use it

To display products, manage the demo cart, and show order confirmation. No data is sold. No advertising tracking is implemented in this demo.

Storage

Data is stored in the Supabase project associated with the application. You may delete your account data by contacting the project owner.

Contact

For questions about this demo, contact the project owner via the repository:
https://github.com/MRRACHIDOMAR/active-ecommerce-demo-clone

This is a minimal policy for a demonstration application. A full policy is required before any public production launch.
