# Active Ecommerce Demo Clone

Clean-room replica of the Active Ecommerce CMS Demo App customer experience.

Built via Replica process (recon → architect → design → build).

## Stack
- Expo (React Native) + TypeScript
- Supabase (planned)
- NativeWind (planned)

## Status
Vertical slice started: Home, Product Detail, Cart (empty), Categories, Profile stubs with demo data.

Planning documents will be added under replica/.

Run with `npx expo start` after installing dependencies.
